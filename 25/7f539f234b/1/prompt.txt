## 2. Design system, motion and explicit "do not" rules

There is no formal design system document. The tokens in `src/styles/vars.css` plus `_Resources/atelier-blush-redesign-plan.md` act as one.

**Motion** (plan, Step 10):
- Cards fade in on scroll: `opacity 0 → 1` and `translateY(20px)` over `0.6s cubic-bezier(0.16, 1, 0.3, 1)`, staggered by 0.1s.

**Layout and grid** (plan, Step 6):
- Asymmetric home grid: `grid-template-columns: 1.15fr 0.85fr`, with every `5n+3` card spanning the full width at 16/9.
- Single column at ≤900px.
- Header container max-width `1320px`.

**Gallery rules** (`docs/gallery-orientation.md`):
- Side-by-side photos must share an orientation: "consecutive portrait images form a two-column row; landscape, square, unknown, and unpaired portrait images span the full gallery width."
- "the gallery expands beyond the text measure up to `1440px`"
- "gutters remain between `10px` and `18px`, including on mobile."
- `npm run check:gallery-orientations` fails the build if the pairing rule is broken.
- "keep width and height metadata intact. `LegacyHtmlPage.astro` uses those dimensions to assign orientation and span classes."

**Explicit "do not" items:**
- Plan: remove the emoji icon buttons (☰ ◉ ⌕ 👜), set `box-shadow: none` on the header, remove the blue dark-mode radial gradient, and remove the announcement bar (recommended Option B, "for the quiet luxury aesthetic").

## 3. Client-side JS and animation hooks

- **Swup** (`Layout.astro:182-194`, bundled module): `new Swup({ containers: ["#swup"], cache: true, animationSelector: "[class*='transition-']", plugins: [new HeadPlugin()] })`. It isn't an Astro integration; `astro.config.mjs` only has react, sitemap, llm-enhancements and robots-txt.
- **Swup CSS** (`src/styles/components/animations.css:5-28`):
  - `.transition-fade` runs a `slideUp` keyframe from `translate3d(0, 4vh, 0)` on load.
  - `html.is-changing .transition-fade` transitions opacity; `html.is-animating .transition-fade { opacity: 0 }`.
  - Note: this `transform` on `#swup` makes it a containing block for any `position: fixed` element inside it.
- **Scroll reveal** (`Layout.astro:196-217`, `is:inline`): an IntersectionObserver (threshold 0.1, rootMargin `0px 0px -40px 0px`) adds `.is-visible` to `.post-card`. It returns early under `prefers-reduced-motion`. The CSS is at `animations.css:31-51` (hidden and translateY(20px) until `.is-visible`, with delays on nth-child 2 and 3).
  - **Gap:** it runs once on first load and is never re-bound after a Swup navigation, so `.post-card`s on a page reached through Swup would stay at opacity 0. This is latent today because nothing renders `PostCard`.
  - **Gap:** Storybook doesn't run this script but does load `animations.css`, so the PostCard stories probably render invisible.
- **Theme** (`Layout.astro:145-161`): sets `data-theme="dark"` from localStorage. There is no toggle in the UI.
- **AnnouncementBar**: inline `onclick` removes the `&lt;aside&gt;`. The component isn't used on any page.
- **DevelopmentBar**: dev-only collapse, copy and Storybook-ping script.
- There is no hamburger menu, no scroll listener, and no `.reveal` or `data-animate` hook. The only other animation is the footer SVG stroke-draw (`site-shell.css:153-176, 242-254`).
